# Golden Era Physique & Sports Nutrition Lab

A complete, zero-dependency personal training roadmap and precision sports nutrition calculator built with Tailwind CSS and Alpine.js.

## Features
- **Golden Era Intro Hero**: Featuring Arnold Schwarzenegger's classic 1974 Olympia pose.
- **TDEE & Macro Engine**: Real-time Mifflin-St Jeor BMR, TDEE, and daily macro targets (Metric & Imperial).
- **Phased Training Roadmap**: Beginner (Months 1–12), Intermediate (Years 1–3), and Advanced (Year 3+) periodization.
- **Interactive Week 1 Workout**: Automatic swaps for equipment (Commercial Gym vs. Home Dumbbells) and injury filters, plus a built-in countdown rest timer.
- **Dynamically Scaled Meal Plan**: Whole-food daily meal portions scaled live to your exact calorie and protein needs.

## Live Deployment
Hosted via **GitHub Pages** directly from `index.html`.
